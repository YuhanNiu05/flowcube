# 通信协议规范

## 1. 概述
本文件定义了 M5Stack 硬件与 Unity 游戏之间的通信协议，包括 JSON 数据包格式、传感器数据结构、流状态定义以及错误处理程序。

## 2. JSON 数据包格式
通信使用 JSON 数据包格式，基本结构如下：
```json
{
  "type": "<message_type>",
  "data": {
    // [内容取决于具体类型]
  },
  "timestamp": "<timestamp>",
  "device_id": "<M5Stack_device_id>"
}
```
- `type`: 消息类型，例如 "sensor_data"、"flow_state" 或 "error"。
- `data`: 包含具体数据内容的对象。
- `timestamp`: 数据包发送的时间戳。
- `device_id`: M5Stack 设备的唯一标识符。

## 3. 传感器数据结构
传感器数据将以以下格式发送：
```json
{
  "temperature": <value>,
  "humidity": <value>,
  "pressure": <value>
}
```

## 4. 流状态定义
流状态将以枚举形式定义：
- **Normal**: 流量正常。
- **Warning**: 流量超限，需要注意。
- **Critical**: 流量超标，可能会导致故障。

## 5. 错误处理程序
错误处理将通过发送/error 类型的数据包来进行：
```json
{
  "type": "error",
  "data": {
    "code": <error_code>,
    "message": "<error_message>"
  },
  "timestamp": "<timestamp>",
  "device_id": "<M5Stack_device_id>"
}
```
- `code`: 错误代码，用于标识特定错误。
- `message`: 错误描述信息。

## 6. 总结
以上为 M5Stack 硬件与 Unity 游戏之间的通信协议规范。所有在实践中遇到的状态和错误应遵循该协议。
